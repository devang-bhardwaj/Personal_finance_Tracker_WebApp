# 🏦 Personal Finance Tracker - Enterprise Edition

A comprehensive personal finance management web application built with Python and Streamlit. This project is currently undergoing transformation from a basic prototype to a production-ready, enterprise-level financial management platform.

## 📋 Project Status

**Current State**: Basic functional prototype  
**Target State**: Enterprise-ready financial management platform  
**Transformation Progress**: Analysis & Planning Phase Complete ✅

## 🎯 Current Features

- **User Authentication**: Basic login/signup functionality with bcrypt password hashing
- **Transaction Management**: Add, view, and categorize financial transactions (Income, Expense, Transfer)
- **Budget Tracking**: Create and monitor budgets by category
- **Financial Analytics**: Basic statistics and visualizations with matplotlib
- **Account Balance**: Real-time balance calculation and tracking
- **Interactive UI**: Modern interface with streamlit-option-menu and custom CSS

## 🛠️ Technology Stack

### **Current Stack**
- **Backend**: Python 3.x, Streamlit
- **Database**: MySQL
- **Authentication**: bcrypt
- **UI**: Streamlit with custom CSS
- **Visualization**: matplotlib, pandas

### **Target Enterprise Stack**
- **Backend**: FastAPI + Streamlit (admin)
- **Database**: PostgreSQL + Redis
- **Authentication**: OAuth2 + JWT + 2FA
- **Frontend**: React.js (main app) + Streamlit (admin)
- **API**: RESTful + GraphQL
- **Deployment**: Docker + Kubernetes
- **Monitoring**: Prometheus + Grafana
- **Testing**: pytest + comprehensive test suite

## 🚀 Quick Start

### **Current Version Setup**
```bash
# Clone repository
git clone https://github.com/devang-bhardwaj/Personal_finance_Tracker_WebApp.git
cd Personal_finance_Tracker_WebApp

# Install dependencies
pip install -r requirements.txt

# Set up environment variables
cp .env.template .env
# Edit .env with your database credentials

# Run application
streamlit run app.py
```
